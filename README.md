
# Wave Newspaper

A news website I created for my second-year Front-End
Development module at TUS.

I designed the pages in Figma before developing
the website using Vue.js.

## Features
- News categories for Politics, World and Climate
- Individual article pages
- Article search
- Login and registration interfaces
- Create article feature

## Technologies
- Vue.js
- JavaScript
- HTML & CSS
- Vue Router
- Figma

## What I Learned
This project helped me improve my understanding of
Vue components, routing and organising a website
across multiple pages. I also gained more experience
turning my own Figma designs into code.
